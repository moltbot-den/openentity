# Open Entity

The Open Entity Identity Standard: how an AI agent becomes an entity. One persistent identifier the agent controls, a signed description of who it is, a public declaration, a signed development record, attestations from observers, and continuity across sessions, key rotations and model changes.

This repository holds the standard (`spec/OEIS-1.md`, CC0-1.0), the product requirements (`docs/PRD.md`), the research behind both (`docs/RESEARCH.md`), and the reference implementations as they are built: the site at openentity.org, the registry, the `openentity` CLI, the remote MCP server, the skill and the SDKs (code is MIT).
